**edit_note_shortcut**: Keyboard shortcut for *Mindful: Edit Note...* in the Browser. Use Qt key names such as `Ctrl+Shift+O` (shown as `Cmd+Shift+O` on macOS), or `""` for no shortcut. An invalid value falls back to `Ctrl+Shift+O`. Changes apply to Browser windows opened afterwards.

**field_font_size**: Font size in points for the HTML field editors (monospace). Use a whole number from `8` to `48`; any other value falls back to `14`. Changes apply to editor windows opened afterwards.
